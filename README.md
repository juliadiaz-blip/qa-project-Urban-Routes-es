# Proyecto de automatización Urban Routes

## Descripción del proyecto

Este proyecto automatiza pruebas para la aplicación Urban Routes utilizando Selenium y Python.
Las pruebas verifican el flujo de solicitud de un taxi, incluyendo el ingreso de direcciones, teléfono, método de pago y mensaje para el conductor.

## Tecnologías y técnicas utilizadas

* Python
* Selenium WebDriver
* Pytest
* Localizadores XPath, ID, CSS Selector y Class Name
* WebDriverWait para esperas explícitas
* Automatización de pruebas UI
